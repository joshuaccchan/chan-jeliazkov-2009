# Chan and Jeliazkov (2009): MATLAB Examples

This repository is retired. Its three scripts are now examples in
[statespace-toolkit](https://github.com/joshuaccchan/statespace-toolkit), rewritten with that
library's functions and reading the same data files.

| Script here | Example in statespace-toolkit |
|---|---|
| `UC.m` | [`ex01_precision_sampler.m`](https://github.com/joshuaccchan/statespace-toolkit/blob/main/examples/ex01_precision_sampler.m) |
| `linreg_tvp.m` | [`ex03_tvp_regression.m`](https://github.com/joshuaccchan/statespace-toolkit/blob/main/examples/ex03_tvp_regression.m) |
| `DFM.m` | [`ex06_dynamic_factor.m`](https://github.com/joshuaccchan/statespace-toolkit/blob/main/examples/ex06_dynamic_factor.m) |

The replication package of the paper is archived in
[bvar-toolkit](https://github.com/joshuaccchan/bvar-toolkit/tree/main/replications/chan_jeliazkov2009_statespace).

Chan, J.C.C. and Jeliazkov, I. (2009). Efficient Simulation and Integrated Likelihood Estimation
in State Space Models, *International Journal of Mathematical Modelling and Numerical
Optimisation*, 1(1/2): 101-120.
